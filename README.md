# John's Save Editors — feedback

This repo tracks **bug reports** and **game requests** for [John's Save
Editors](https://johnhumphrys.github.io/johns-game-save-editor/) — free,
browser-based save file editors for PC games.

- Found a bug? [Open an issue](https://github.com/johnhumphrys/johns-save-editors/issues/new?labels=bug).
- Want a save editor for a game that isn't listed?
  [Request it](https://github.com/johnhumphrys/johns-save-editors/issues/new?labels=game-request).

The editor's source code lives in a separate, private repository.
